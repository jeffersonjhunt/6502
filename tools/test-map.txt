# Paths to test labels (hw/testing.md, "The plan", item 2), read by tools/test_map.py and so by
# `tools/check.sh changed`.
#
# One rule a line: a pattern, then the labels a change to a matching path chooses. The first rule that
# matches a path is the one that counts, so a specific rule goes above a general one. A pattern ending
# in / matches everything under that directory; any other is a glob over the whole path (fnmatch: *
# crosses /). Every path git tracks must match some rule: `tools/test_map.py check`, the suite
# test_test_map, fails on one that doesn't.
#
# A label is one the suites carry (emulator/test/host/CMakeLists.txt, "Labels"), or one of:
#   all    every label: the emulator's core, which every suite runs
#   self   the suite the file is named for (emulator/test/host/test_NAME.cpp or .py: test_NAME)
#   web    the WebAssembly build and its tests, vitest, the page build, the e2e smoke set
#   none   nothing to run: prose, editor settings, code no test runs (every build still builds it)
# or a suite's name (test_NAME), for a file only that suite reads.
#
# The labels on the suites were checked against coverage (tools/test_coverage.py, hw/testing.md item 7):
# rerun it when a device or a suite is added.

# --- the devices: one label each -----------------------------------------------------------------------

# SIDs the sound card's), and every card of machines/backplane.machine chooses `backplane` too: the suites
# that build that machine run every card on it (its reset, its registers probed by the BIOS), so a change to
# any card can break them. Coverage says so (tools/test_coverage.py). Each of those, and the files the
# session runs a card's media or a tune through, chooses `web` too: they are all in oo1.wasm, which the page
