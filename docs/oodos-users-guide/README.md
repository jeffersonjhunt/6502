# OODOS User's Guide

For whoever sits at the `A>` prompt: the command line, drives and file names, the CCP's built-in commands, the
utilities, and what the errors mean. It follows the outline of CP/M 3's User's Guide, in our own words. Writing
programs is the [Programmer's Guide](../oodos-programmers-guide/README.md). How the books are kept is in
[docs/README.md](../README.md).

1. [Introduction](01-introduction.md): starting OODOS, the prompt
2. [The command line](02-command-line.md): typing and editing, several commands, where programs are found
3. [Drives and file names](03-drives-and-files.md): drives, users, names, wildcards, attributes, passwords
4. [Built-in commands](04-built-in-commands.md): DIR, DIRSYS, ERASE, RENAME, TYPE, USER, GO, CLEAR, CLS, WOZMON,
   APPLE2
5. [Utilities](05-utilities.md): SET, SHOW, INITDIR, DATE, DEVICE, SETDEF; PIP (4b2); SUBMIT, GET, PUT (phase 5)
6. [Errors](06-errors.md)

**Written so far:** the skeleton (G0), and G1: every chapter, for OODOS phases 0-4. SUBMIT, GET and PUT come
with phase 5.
