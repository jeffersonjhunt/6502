# The translation ledger (hw/oodos.md, "The plan, phase 7": the source and the licence).
#
# One line for each routine of Microsoft's GW-BASIC (microsoft/GW-BASIC at edf82c2) the port needs, and what
# became of it:
#
#   FILE.ASM LABEL -> res/x.s LABEL     translated, resident (or p1/..., p2/... in a block)
#   FILE.ASM LABEL -> OEM res/x.s LABEL replaced by the OO-1's own code
#   FILE.ASM LABEL -> later 7b          a later sub-phase's (the plan's 7b-7g)
#   FILE.ASM LABEL -> dropped: why      not needed on the OO-1
#
# tools/ledger.py checks it: against the source (every label named is there) and against the build's maps (every
# 6502 label named is there).
