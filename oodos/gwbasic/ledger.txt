# The translation ledger (hw/oodos.md, "The plan, phase 7": the source and the licence).
#
# One line for each routine of Microsoft's GW-BASIC (microsoft/GW-BASIC at edf82c2) the port needs, and what
# became of it:
#
#   FILE.ASM LABEL -> res/x.s LABEL     translated, resident (or p1/..., p2/... in a block)
#   FILE.ASM LABEL -> OEM res/x.s LABEL replaced by the OO-1's own code
#   FILE.ASM LABEL -> later 7b          a later sub-phase's (the plan's 7b-7g)
#   FILE.ASM LABEL -> dropped: why      not needed on the OO-1
#
# tools/ledger.py checks it: against the source's names (every label named is there, and every routine a translated
# one calls, jumps into or names in a dispatch table has its line) and against the build's maps (every 6502 label
# named is there). The Makefile's default target runs it, with srcnames.txt, the source's names made from the
# source by `ledger.py --src ... --write-names srcnames.txt`, so the build needs no copy of the source.
# The spike's (oodos/spike/gwbasic/, carried into res/ at 7a's start)
#
# Filled at step I2: every routine of GWMAIN.ASM, GWEVAL.ASM and BIMISC.ASM the spike translated (the statement
# loop and CHRGTR, FNDLIN, LINGET, GOTO, DATA and REM, LET, IF; the formula evaluator; SYNCHR, GETSTK, ISLET2),
# and those the translated routines call that had no line. The labels inside a routine that matter are named too.
